# Tactical PM Command Center | 战术 PM 指挥中心 🐈💎

一款专为产品经理（PM）打造的**高审美、轻量化、硬核决策**移动端项目管理工具。

---

## 🌟 核心亮点 | Highlights

- **黑金玻璃态设计 (Glassmorphism)**：极致的审美追求，毛玻璃质感配合极光渐变，让工具也成为艺术品。
- **RICE + 现实因子模型**：在经典的 RICE 评估模型基础上，独创“老板重视度”与“技术阻力”修正系数，让决策更接地气。
- **双轨全周期甘特图**：
    - **自适应时间轴**：自动适配从数天到数月的全周期跨度。
    - **计划 vs 实际 (Plan/Real)**：双线并行展示，一眼洞察项目执行偏差。
- **国际化支持**：中英文一键无缝切换，适配全球化办公环境。
- **单文件便携性**：100% 纯本地运行，所有数据通过 `LocalStorage` 存储在用户手机中，无服务器依赖，隐私安全。

---

## 🛠️ 功能指南 | Features

1. **决策墙 (Decision Wall)**：快速录入需求，自动计算优先级得分并排序。
2. **深度管理 (Detail Config)**：点击卡片进入详情，管理负责人、起止日期及项目描述。
3. **甘特图 (Timeline)**：基于周刻度自动绘图，支持横向平滑滚动，锁定项目脉络。
4. **效率工具**：支持一键“复制卡片新增”，告别重复录入。
